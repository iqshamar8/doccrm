# WhatsApp Setup
1. Meta for Developers -> WhatsApp -> Cloud API.
2. Create app, add WhatsApp product, generate Access Token.
3. Phone Number ID + Verify Token.
4. Webhook URL: https://<host>/api/whatsapp/webhook
5. Set env: WHATSAPP_ACCESS_TOKEN, WHATSAPP_PHONE_NUMBER_ID, WHATSAPP_VERIFY_TOKEN, WHATSAPP_APP_SECRET, WHATSAPP_API_VERSION=22.0
